# UI by product type (phases 6–8)

Pick the branch that matches what you are building, on top of phase 6:

- **Web / landing page:** `impeccable` (shape the page in its Persuade mode, commit to one bold direction) → `copywriting` (landing copy in the `BRAND.md` voice) → `impeccable` polish.
- **Dashboard / admin / data app:** `shadcn` (components + blocks, charts via shadcn charts) + `impeccable` in its Operate mode for a non-default look; `ui-ux-pro-max` lookups for chart types (`--domain chart`) and dense palettes. Rules: one hero metric per view (a dashboard's brief earns it — do not carry the big-number template over to a landing page, `impeccable` refuses it there), max 4–6 KPI tiles, real-looking seeded data (never lorem / 0s), one accent colour for "the number that matters", consistent chart colours across the page. Finish with `impeccable` polish.
- **Mobile app (Expo / React Native):** `expo-overview` → `expo-router` (navigation) → `expo-design-system` + `expo-native-ui` / `expo-ui` (native look, not a shrunk website) → `expo-animation` for motion and haptics; `vercel-react-native-skills` for performance/best practice; `apple-design` for iOS-quality feel. Demo it on a real phone via Expo Go.
- **Mobile web / PWA (a web app demoed on a phone):** web branch + `mobile-native` (100vh bug, notch, tap highlight, input zoom) + `apple-design`.
- **Native iOS (SwiftUI):** `apple-design`, `mobile-native`; `impeccable` has native audit references.
